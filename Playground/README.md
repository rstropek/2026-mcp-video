# Playground

A simple C# console application that demonstrates the Fibonacci sequence.

## Description

This project prints the first 20 numbers in the Fibonacci sequence to the console.

## Requirements

- .NET 10.0 SDK

## Running the Application

To run the application, navigate to the Playground directory and execute:

```bash
dotnet run
```
